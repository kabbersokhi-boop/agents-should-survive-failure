## Limitations

The evidence covers the reference vendor-onboarding workflow and a preview managed-agent runtime. External packages are trusted operator-installed code. Docker is not hostile-code isolation. NVIDIA NIM live checks are credential-gated and are not part of public CI. Read the [full limitations](../limitations.md) and [threat model](../threat-model.md) before adapting the design.
